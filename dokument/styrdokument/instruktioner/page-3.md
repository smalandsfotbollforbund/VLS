# Page 3

Definition: Instruktioner beskriver uppdrag, ansvar, mandat och förväntningar för en roll, funktion eller särskild organisatorisk uppgift.

Ska användas för: Distriktschef, kommittéordförande, kommittéledamot, valberedningens arbetssätt, attestroller eller särskilda samordningsfunktioner.

Ska inte användas för: Att skapa ny beslutanderätt utan stöd i delegationsordning.

Risk: Att befattningsbeskrivningar börjar användas som styrande mandatdokument utan tydlig koppling till distriktsstyrelsens beslut.
