# Krishantering

En kris är en situation som kräver snabba beslut, som hotar distriktets förmåga att fullgöra sitt uppdrag eller som kan skada förtroendet för organisationen — och som den ordinarie styrningskedjan inte hinner hantera i sin normala takt.

Krishantering är inte en ersättning för den ordinarie styrningen. Det är ett undantag som aktiveras när den ordinarie styrningen inte räcker till.

## Vad är en kris?

En kris kan uppstå inom flera dimensioner:

<table data-view="cards"><thead><tr><th></th></tr></thead><tbody><tr><td><strong>Ekonomisk kris</strong><br>Akut underskott, oförväntad intäktsbortfall eller händelse som hotar likviditeten.</td></tr><tr><td><strong>Operationell kris</strong><br>Tävlingsverksamhet som inte kan genomföras, kritiskt systemhaveri, nyckelperson som plötsligt inte kan fullgöra sitt uppdrag.</td></tr><tr><td><strong>Rykteskris</strong><br>Händelse som skadar förtroendet för distriktet hos föreningarna, media eller allmänhet.</td></tr><tr><td><strong>Integritetsrisk</strong><br>Allvarliga regelbrott, anklagelser om oegentligheter eller handlingar som strider mot SmFF:s värdegrund.</td></tr></tbody></table>

## Vem gör vad i en kris?

{% stepper %}
{% step %}
**Identifiera och aktivera**\
Den person som först identifierar en potentiell kris kontaktar distriktsordföranden eller distriktschefen omedelbart. Vänta inte på nästa ordinarie möte.
{% endstep %}

{% step %}
**Bedöm och besluta om krisläge**\
Distriktsordföranden, i samråd med distriktschefen, bedömer om situationen kräver aktivering av krisledning. Vid allvarliga situationer informeras hela presidiet.
{% endstep %}

{% step %}
**Aktivera krisledning**\
Prcsidiet, med stöd av distriktschefen, tar ett samlat grepp om situationen: vad vet vi, vad behöver vi veta, vem kommunicerar, vilka beslut behöver fattas?
{% endstep %}

{% step %}
**Beslut och åtgärder**\
Prcsidiet har distriktsstyrelsens delegation för brådskande beslut inom de ramar som delegation ger. Vid beslut utanför delegationen krävs ett extra styrelsesammanträde, som kan hållas digitalt.
{% endstep %}

{% step %}
**Kommunikation**\
All extern kommunikation under en kris ska koordineras. Normalt kommunicerar distriktsordföranden eller distriktschefen. Parallella eller okoordinerade budskap från styrelseledamöter förvärrar kriser.
{% endstep %}

{% step %}
**Återgång och utvärdering**\
När akutläget är över sker en ordinarie styrelsebehandling. Vad hände? Vad fungerade? Vad behöver ändras för att minska risken eller förbättra hanteringen nästa gång?
{% endstep %}
{% endstepper %}

## Krisledning är inte en parallell styrning

Prcsidiet kan fatta brådskande beslut inom sin [delegation](../ledning/delegation.md). Utöver det krävs styrelsebeslut — men styrelsen kan sammankallas med kort varsel och mötas digitalt.

En kris ger inte presidiet rätt att agera utanför delegationen. Den ger anledning att kalla styrelsen snabbt.
