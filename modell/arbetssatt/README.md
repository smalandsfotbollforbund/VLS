# Processer och arbetssätt

Processer och arbetssätt beskriver hur organisationens löpande arbete fungerar i praktiken — hur frågor bereds, hur beslut fattas på rätt nivå, hur genomförandet håller sig inom beslutade ramar och hur arbetet dokumenteras och följs upp.

[Beredning, beslut och verkställighet](beredning-beslut-och-verkstallighet.md) är kärnan i ansvarskedjan. [Uppföljning och återrapportering](uppfoljning-och-aterrapportering.md) säkerställer att rätt nivå kan ta ansvar för resultaten. [Dokumentation och protokoll](dokumentation-och-protokoll.md) skapar spårbarhet och ordning. [Möteshantering](moteshantering.md) ger praktiska förutsättningar för att möten ska fungera effektivt.
