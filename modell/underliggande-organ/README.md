# Underliggande organ

Underliggande organ är de strukturer som distriktet använder för att hantera sakkunskap, bereda frågor och genomföra uppdrag — utan att skapa egna beslutsvägar vid sidan av distriktsstyrelsen.

[Kommittéerna](kommitteer.md) ger distriktet kraft i sakfrågorna och verkar på den taktiska nivån med ansvar inom bestämda verksamhetsområden. [Arbetsutskott](arbetsutskott.md) tillsätts av distriktsstyrelsen för strategiska eller tvärfunktionella beredningsuppdrag. [Arbetsgrupper](arbetsgrupper.md) tillsätts av kommittéerna för avgränsade, tidsbestämda uppdrag — normalt max 3–6 månader. [Referensgrupper](referensgrupper.md) förstärker arbetet med råd och perspektiv utan att ha besluts- eller genomförandeansvar.
