# Organisationsstruktur

Organisationsstrukturen beskriver hur Smålands Fotbollförbund är uppbyggt som styrsystem — inte bara vilka delar som finns, utan hur de hänger ihop och vilka relationer de har till varandra.

[Styrarkitekturen](styrarkitektur.md) ger en helhetsbild av de fem nivåerna och hur mandaten är fördelade. [Ansvar och roller](ansvar-och-roller.md) förklarar de vanligaste begreppen för vad som förväntas av olika funktioner. [Ansvarsmatrisen](ansvarsmatris.md) visar den konkreta ansvarskedjan i olika typer av frågor. [Förhållande i idrottens ekosystem](forhallande-i-idrottens-ekosystem.md) sätter distriktet i relation till Riksidrottsförbundet, Svenska Fotbollförbundet och övriga distrikt.
