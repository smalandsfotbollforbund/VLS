# Distriktsstyrelsen och ledningen

Distriktsstyrelsen leder distriktet mellan de demokratiska mötena. Den får sitt mandat från föreningarna via årsmötet och bär det övergripande ansvaret för verksamhet, ekonomi och organisation.

[Distriktsstyrelsen](distriktsstyrelse.md) håller riktning, ramar och uppföljning. [Presidiet](presidium.md) stödjer styrelsens arbete utan att vara ett parallellt beslutsorgan. [Distriktschefen](distriktschef.md) leder den löpande verksamheten inom beslutade ramar. [Kansliet](kansli.md) genomför och administrerar verksamheten i vardagen. [Delegation](delegation.md) reglerar hur beslutanderätt förs vidare på ett kontrollerat sätt. [Intern kontroll och attest](intern-kontroll-och-attest.md) beskriver hur distriktets ekonomiska ansvarshantering är organiserad.
