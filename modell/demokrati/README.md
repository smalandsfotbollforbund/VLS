# Demokratisk styrning

Demokratisk styrning är grunden för hela styrmodellen. Distriktets mandat kommer från medlemsföreningarna, och det är i de demokratiska organen som föreningarnas vilja omsätts i beslut och inriktning.

[Årsmötet](arsmote.md) är det högsta beslutande organet. [Representantskapet](representantskap.md) beslutar i tävlingsfrågor. [Val, ombud och rösträtt](val-ombud-och-rostratt.md) förklarar de formella förutsättningarna för deltagande. [Motioner och initiativrätt](motion.md) är föreningarnas direkta väg att sätta frågor på dagordningen. [Demokratisk legitimitet och medlemsinflytande](demokratisk-legitimitet-och-medlemsinflytande.md) förklarar principerna bakom hur inflytandet är organiserat.
